# إعادة تصميم موقع شركة المزبورة للخدمات اللوجستية

نسخة إنتاجية بصيغة صفحة واحدة (One-page) ذات تجربة ثنائية اللغة كاملة (عربية RTL + إنجليزية LTR) مع حفاظ صارم على هوية اللون الأحمر (#C62828 / #A30000) وبناء كامل على المحتوى الموثّق المستخرج من الموقع الرسمي — بلا أي بيانات مُختلقة.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | البنية الكاملة: الهيدر، الهيرو، الأرقام، العملاء، من نحن، أبرز الأعمال والرحلة، الخدمات الـ7، المعدات الـ8، آلية العمل، معرض الأعمال، الأسئلة الشائعة، التواصل والنموذج، الخريطة، الفوتر + JSON-LD (Organization + FAQPage) + أوسمة SEO/OG |
| `assets/css/styles.css` | نظام تصميم بمتغيرات (tokens)، RTL-first بخواص منطقية مع دعم LTR كامل، حركات transform/opacity فقط، دعم `prefers-reduced-motion`، نقاط توقف 620/900/1080/1440/1800 |
| `assets/js/i18n-dictionary.js` | القاموس الثنائي: 208 مفاتيح متطابقة عربي/إنجليزي — النص العربي حرفي من الموقع، والإنجليزي ترجمة احترافية |
| `assets/js/app.js` | التطبيق: تبديل اللغة (lang/dir/عنوان/OG) مع حفظ التفضيل + `?lang=en` + فدر `localStorage` (`almazboura-lang`)؛ قائمة الجوال (تركيز + ESC + حصر Tab)؛ صكوك الظهور والعدّادات؛ المعجّن الضوئي للصور مع لوحة المفاتيح حسب الاتجاه؛ الأسئلة حصرية؛ التحقق من النموذج + إرسال عبر بريد/واتساب برسالة معدّة ثنائية اللغة |

## المحلي

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا ساكنًا:

```
cd almazboura
python -m http.server 8080
```

## الملاحظات

- الصور والشعار والخطوط تُحلَّ حاليًا (hotlink) من `almazboura.com` — استنسخها إلى `assets/img` عند النشر المستقل وحدّث المسارات.
- فيديو «حمولات استثنائية» محلي في `assets/media/` (نسخة mp4 + mov الأصلية)، ويُشغَّل صامتًا فقط أثناء ظهوره، ويتوقف مع `prefers-reduced-motion`.
- صور محلية جديدة: خلفية الواجهة `assets/images/hero-pipes.jpg` (فولفو + أنبوب ضخم وقت الغروب، بطبقة شفافة فوقها) وصورة معرض الأعمال `assets/images/works-xl.jpg` (أكتروس + أنابيب فلنچات).
- النموذج يفتح `mailto:` أو `wa.me` برسالة معدّة؛ الربط بنهاية خلفية حقيقية متاح عند توفّر الـ repo.
- التّخصيص المنتجي القادم: دمج هذا الملف في Next.js الحالي (حاليًا معزول عن المستودع).
